# `ClassSMP`

A lightweight class system made for a private Minecraft SMP.

```text
MINER       → Haste
FIGHTER     → Strength
SUPPORT     → Healing
```

Class effects scale with the player's level.

### Commands

```text
/setclass <class>
/setlevel <level>
/rerollclass
```

Reroll cost:

```text
1x Gold Block
1x Netherite Block
7x Diamond
```

### Tech

```text
Java
Fabric
Minecraft
```
